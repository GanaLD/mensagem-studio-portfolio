CASE DO PROJETO

Três templates. Um projeto.

O objetivo deste case é reunir experiências web editáveis e demonstrar como interfaces, motion e interações podem ser adaptados para diferentes produtos, marcas e campanhas.

Contexto

Cyber Ronin, a experiência automotiva e LTX usam linguagens visuais diferentes, mas pertencem ao mesmo núcleo de experimentação em HTML e front-end.

Interação

Spotlight reveal, hotspots, hover, transições e estados interativos são executados dentro dos próprios templates.

Responsividade

Os três projetos estão reunidos no mesmo case, com comportamento responsivo.

Entrega

Um único case de portfólio contendo os três HTMLs, sem alterar o tema global da Mensagem Studio.
